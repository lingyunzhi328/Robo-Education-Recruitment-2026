# 排查记录与课前检查

1. `ros2` 找不到：确认已安装正确发行版，每个新终端执行 `source /opt/ros/jazzy/setup.bash`。
2. 海龟不动：查节点列表、话题名称、消息类型、发布者和订阅者数量，确认没有同时运行键盘与自动控制器。
3. 跨组出现陌生节点：统一组内 `ROS_DOMAIN_ID`，修改后重新启动节点。
4. 自写代码可运行但通信不通：查话题名、消息类型和 QoS 是否兼容，先用官方 CLI 发布命令分离问题。
5. 点位控制绕远：查 `atan2` 的参数顺序与角度误差归一化，限制角速度，先转向再前进。
